Frequently Asked Questions

How do I set up Packet?

See the Getting Started Guide in our repository.

Is Packet open source?

Yes! The client applications (Android and iOS) are fully open source. You can review the code on GitHub.

Does Packet log my activity?

No. Packet operates on a zero-knowledge principle. We do not log, store, or monitor any user activity. See our Privacy Policy for details.

How do I deploy Packet?

Use the deploy-vps.sh script in the repository to deploy the server. See the README for detailed instructions.
